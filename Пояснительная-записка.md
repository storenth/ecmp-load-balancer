## Пояснительная записка
### Топология
Статическая топология может быть создана с использованием Docker
### Трафик
- Для генерации трафика достаточно ICMP пакетов `ping dest-IP` с двух source-IP
- Захват осуществляется на интерфейсах в сторону сети назначения на VM с функцией ECMP-роутера
### Анализ результатов
Для простоты верификацию можно сделать с использованием tshark: один и тот же IP не должен встречаться в обоих pcap-файлах.
### Отчет
Для отчета требуется составление тест-плана, например по стандарту ISO/IEC/IEEE 29119-3 чтобы
Финальный отчет содержал степень достижимости заявленым в плане целям, соответствию RFC 2991, 2992, 2544, 2330, результаты прогона и выводы на основе метрик (например Deviation, Entropy, Chi-square)
### Ограничения
- Создана статическая топология, для динамической рекомендуется использовать FRR
- Не ставилась задача верифицировать Resilient Hashing, Symmetric Hashing и др
